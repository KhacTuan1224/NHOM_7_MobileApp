# Android packages

APK files are generated by [`.github/workflows/android-package.yml`](../.github/workflows/android-package.yml).
The workflow writes build outputs to this directory and publishes them as a
GitHub Actions artifact named **Packages**. Builds from version tags (`v*`)
also attach the APK and SHA-256 checksum to a GitHub Release.

Generated APKs are not committed to this directory or Git history. Download
the artifact from the workflow run, or use the Releases page for a tagged
build.
