# Kho khuyến mãi đã ngừng sử dụng

Đã gỡ tính năng khuyến mãi sản phẩm/lô, kho khuyến mãi và càng mua càng giảm.
Các API `/promotions/*` không còn tồn tại; các collection cũ bị Rules từ chối truy cập.
Hướng dẫn chuyển đổi, sao lưu và kết quả dọn database: [discount-retirement.md](discount-retirement.md).
